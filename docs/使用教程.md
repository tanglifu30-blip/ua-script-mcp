# 使用教程

## 1. 怎么提需求

一句话说清这几项，写出来的脚本会准很多：

| 项 | 为什么重要 | 例子 |
|----|-----------|------|
| 游戏名、品类 | 决定查哪类套路 | 山河策，SLG |
| 核心玩法 | 脚本结尾要交给真实玩法，AI 得知道玩法是什么 | 三国赛季制沙盘，按真实地形行军 |
| 卖点 | 每条脚本通常只讲一个卖点，给 2 到 4 个最好 | 可以托管不用熬夜；赛季重置同起点 |
| 目标用户 | 素材也在筛人：要吸引谁、劝退谁 | 25-45 岁男性，喜欢历史 |
| 时长 | 口播字数按时长算 | 30 秒 |
| **制作限制** | 不写的话，AI 可能会写真人或 CG，你们拍不了 | 只能用游戏录屏加配音 |

模板：

> 用 ua-script 帮我写 3 条买量脚本。游戏：xxx，品类：xxx，核心玩法：xxx，卖点：xxx；xxx，目标用户：xxx，时长 30 秒，制作限制：xxx。

客户端支持 MCP 提示模板的话，也可以直接选 `write_ua_script`，按表单填写。

可选的品类：传奇、仙侠、MMO、SLG、卡牌、二次元、休闲、消除、合成、动作、Roguelike、放置。写别的品类，AI 只能拿到通用套路。

## 2. AI 拿到需求后会做什么

1. **查套路**（`get_creative_patterns`）：按品类拿到几条套路，每条脚本用一条不同的套路。
2. **写脚本**：表格格式，每一镜写清楚时间、画面、口播、字幕。
3. **合规初筛**（`check_compliance`）：查出"最强""唯一""送 648""十连必出"这类说法，AI 会自己改。
4. **分镜检查**（`build_storyboard`）：口播念不念得完、前 3 秒有没有钩子、静音时有没有字幕、结尾有没有交给真实玩法。
5. **保存**（`save_script`）：每条脚本拿到一个编号，比如 `s_UeXn6QjR`。
6. **交付**：脚本、思路说明，以及**录屏前要人工核对的事项**（比如"托管功能是否真的能做到口播里说的"）。

完整过程见 [案例 1](../examples/01-SLG.md)。

## 3. 怎么给反馈（很重要）

脚本交付后，AI 会问哪几条会用。直接回答就行：

> 第 3 条直接用。第 1 条要改：第 1 镜口播改成"凌晨三点，城被偷了"，其他不变。第 2 条不用，我们没有这个录屏素材。

AI 会把它记下来（`submit_feedback`）。**改过的地方是最有价值的反馈**，它直接告诉我们工具哪里写得不对。

另外两种情况，也直接告诉 AI：

- **被平台拒审了**：「这条在巨量引擎被拒了，原因是：……」，把平台给的原因原文贴过去，AI 会调用 `report_rejection`。
- **投出去有数据了**：「s_xxx 这条点击率 3.2%，转化率 1.1%，消耗 5000」，AI 会调用 `record_performance`。

## 4. 其他用法

**拆解竞品素材**：把一条素材的口播文字稿发给 AI，说「用 ua-script 拆解这条素材」（或者用提示模板 `deconstruct_creative`）。AI 会按七层心流拆开，对照套路库归类，告诉你值得学的地方和合规风险。

**保存团队自己的套路**：「把这个写法存成我们自己的套路：……」。AI 会调用 `add_private_pattern`，以后查套路时会一起返回。只有你自己能看到。

**改单条**：「把 s_xxx 改成 15 秒版」「第 2 条换一个开头」。改完让 AI 重新做合规和分镜检查。

**查以前的脚本**：「列出我最近保存的脚本」（`list_scripts`）。

## 5. 工具一览

| 工具 | 作用 |
|------|------|
| `get_creative_patterns` | 按品类、关键词查套路 |
| `check_compliance` | 合规关键词初筛 |
| `build_storyboard` | 分镜解析和时长检查 |
| `save_script` / `list_scripts` | 保存脚本 / 查看已保存的脚本 |
| `submit_feedback` | 记录采用情况和定稿 |
| `report_rejection` | 记录平台拒审原因 |
| `record_performance` | 记录投放数据 |
| `add_private_pattern` | 保存团队自己的套路 |

## 6. 要知道的限制

- **合规检查只是关键词初筛**，不能代替平台审核和法务意见。平台的游戏审核细则还没接入。
- 套路库目前有 17 条，都还在内测打磨中。案例大多来自 2018 到 2022 年的公开素材，也包括一部分 2025 到 2026 年的出海案例。
- AI 写的脚本是**初稿**。玩法、数值、福利、活动时间都要对照游戏实际情况核对，否则可能被判为假玩法或虚假宣传。
