# 数据与隐私

## 存了什么

| 数据 | 什么时候存 |
|------|-----------|
| 你保存的脚本（标题、正文、用了哪些套路、游戏名、品类） | AI 调用 `save_script` 时 |
| 采用情况、原因、你改好的定稿 | AI 调用 `submit_feedback` 时 |
| 拒审原因、被拒的句子 | AI 调用 `report_rejection` 时 |
| 投放数据 | AI 调用 `record_performance` 时 |
| 你自己的套路 | AI 调用 `add_private_pattern` 时 |
| 调用记录：哪个工具、什么时候、品类和套路 id 这类参数 | 每次调用都会记，**不记录脚本全文和游戏名** |

你和 AI 的对话内容我们看不到，只能看到 AI 调用工具时传过来的内容。

## 谁能看到

- **其他用户看不到你的任何数据。** 数据按密钥分开存放，查询时只返回你自己的。
- **发放人**能看到汇总统计，比如每条套路的采用率、修改幅度、拒审原因。前提是你在领密钥时**同意了**把数据用于改进；不同意的话，你的数据不会进入任何汇总。汇总里不会出现游戏名。
- 服务器上的数据库每天备份一次，备份存放在私有位置。

## 密钥

服务器只保存密钥的哈希值，不保存密钥本身。密钥丢了也找不回来，只能停用后重新发一个。

## 删除

找发放人，说明要删除数据。服务器上属于你这个密钥的全部数据都会被删除，密钥也会停用。

注意：已经做过的每日备份里可能还保留着删除前的数据。

## 同意可以撤回

领密钥时同意了数据用于改进，之后想撤回，找发放人改成"不同意"即可。从撤回那一刻起，你的数据就不会再进入汇总。
