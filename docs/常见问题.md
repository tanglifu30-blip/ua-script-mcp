# 常见问题

## 接入

| 现象 | 原因和处理 |
|------|-----------|
| AI 说「没有提供密钥」 | 请求头没有配上。检查 `Authorization` 这一行；Codex 检查环境变量 `UA_SCRIPT_KEY` 是否生效（设置后要重开终端） |
| 「密钥格式不对」 | 密钥要以 `uas_` 开头。Codex 的环境变量里不要加 `Bearer` |
| 「密钥无效」 | 密钥复制得不完整，或者请求头里漏了 `Bearer ` |
| 「密钥已过期」 | 30 天有效期到了（从你第一次使用时算起）。想继续用，可以在 [dc.jinqianbao.icu](https://dc.jinqianbao.icu) 再买一个，或者找发放人延期 |
| 「密钥已停用」 | 找发放人 |
| `/mcp` 里看不到 ua-script | 配置改完要重启客户端或者新开会话 |
| 连接超时 | 检查网络能不能打开 `https://mlch.jinqianbao.icu/healthz`，能打开就会显示 `{"ok":true,...}` |
| AI 只回复「你想让我做什么」 | 只发仓库地址或文档，AI 不知道要做什么。要明确说「按这个仓库帮我接入」或者直接下写脚本的任务 |

## 使用

**Q：合规检查没报问题，平台还是拒审了？**
合规检查只做关键词初筛，查不出画面问题，也没有接入平台的审核细则。请把拒审原因原文告诉 AI，我们会根据这些补充规则。

**Q：AI 写了真人出镜或 CG，我们拍不了。**
需求里写明制作限制，比如"只能用游戏录屏加配音"。

**Q：写出来的脚本和我们游戏对不上。**
把核心玩法写得具体一点。AI 交付时会列出"录屏前要核对的事项"，请逐条看。核对不上的地方让 AI 改。

**Q：我的品类不在列表里？**
AI 只能拿到通用套路。可以选最接近的品类，或者用 `add_private_pattern` 存你们自己的套路。

**Q：能一次写 10 条吗？**
能，但每条的质量会下降，建议一次 3 到 5 条。

## 其他

**Q：试用期怎么算？**
30 天，从你**第一次调用工具**的那一刻开始算。只是把配置加上、还没用，不计时。到期后工具会返回「密钥已过期」，找发放人延期即可，之前保存的脚本和反馈都还在。

**Q：密钥丢了或者泄露了？**
马上找发放人停用，再发一个新的。

**Q：在店铺买了，激活码在哪？**
店铺不发邮件。付款后在订单详情页查看，请记下订单号。

**Q：怎么删除我的数据？**
见 [数据与隐私.md](数据与隐私.md)。
