# 各客户端的接入方法

所有客户端填的都是同样两样东西：

- 地址：`https://mlch.jinqianbao.icu/mcp`
- 请求头：`Authorization: Bearer uas_你的密钥`（`Bearer` 和密钥之间有一个空格）

下面的 `uas_...` 都要换成你自己的密钥。

## Claude Code

在终端执行一次：

```bash
claude mcp add --transport http ua-script https://mlch.jinqianbao.icu/mcp --header "Authorization: Bearer uas_..."
```

默认只在当前目录生效。想在所有项目里都能用，在 `add` 后面加 `--scope user`。

检查：新开一个会话，输入 `/mcp`，能看到 `ua-script` 显示已连接。

## Codex（OpenAI）

1. 编辑 `~/.codex/config.toml`（Windows 上是 `C:\Users\你的用户名\.codex\config.toml`，没有就新建），在末尾加：

   ```toml
   [mcp_servers.ua-script]
   url = "https://mlch.jinqianbao.icu/mcp"
   bearer_token_env_var = "UA_SCRIPT_KEY"
   ```

2. 把密钥设成环境变量 `UA_SCRIPT_KEY`。这里**只填 `uas_...`，不要加 `Bearer`**，Codex 会自动加。
   - Windows（PowerShell）：`setx UA_SCRIPT_KEY "uas_..."`，然后关掉终端重新打开
   - macOS / Linux：在 `~/.zshrc` 或 `~/.bashrc` 里加 `export UA_SCRIPT_KEY="uas_..."`，然后 `source` 一下

3. 检查：重启 Codex，输入 `/mcp`，能看到 `ua-script` 和它的工具。

## Cursor

编辑 `~/.cursor/mcp.json`。只想在某个项目里用的话，改项目里的 `.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "ua-script": {
      "url": "https://mlch.jinqianbao.icu/mcp",
      "headers": { "Authorization": "Bearer uas_..." }
    }
  }
}
```

如果文件里已经有 `mcpServers`，只把 `"ua-script": {...}` 这一项加进去，不要覆盖已有的内容。

检查：Cursor 设置 → MCP，`ua-script` 显示为绿色。

## Cherry Studio 等桌面客户端

在设置里找「MCP 服务器」→ 添加：

| 项 | 填什么 |
|----|--------|
| 名称 | ua-script |
| 类型 | Streamable HTTP（有的客户端叫 streamableHttp、可流式传输的 HTTP） |
| 地址 | `https://mlch.jinqianbao.icu/mcp` |
| 请求头 | `Authorization` = `Bearer uas_...` |

只支持 SSE 或者只支持本地命令（stdio）的客户端接不了。
